## November 3, 2016

Quiz for Sections 4.4 and 4.5. Source file: `Fall2016-Quiz4.5-4.6.pdf`.

### Problem 1

Suppose S = {1 + 2x, 1 + x + x² + x³, 1 − 2x + x³, x + 2x²}. Is S a basis for P₃? Why or why not?

## November 1, 2018

Quiz for Sections 4.4 and 4.5.

### Problem 1

Find all real numbers t for which the set S = {(t, 1, 1), (1, t, 1), (1, 1, t)} is linearly independent.

### Problem 2

Decide if the set S = {(1, 0, 0, 1), (0, 2, 0, 2), (1, 0, 1, 0), (0, 2, 2, 0)} is a basis for ℝ⁴. Explain your reasoning.
