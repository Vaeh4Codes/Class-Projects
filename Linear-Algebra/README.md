# Elementary Linear Algebra

Study library for **Elementary Linear Algebra, 8th edition** by Ron Larson (Cengage). Use this folder as context when reviewing sections, working practice problems, or looking up class materials.

## Layout

| Folder | What goes here | In git? |
| --- | --- | --- |
| `textbook/` | Your copy of the textbook PDF | No. Local only. |
| `private/` | Anything else that should stay off GitHub (solution files, unscanned originals) | No. Local only. |
| `class/` | Syllabus, lecture notes from class, homework prompts, exams | Yes |
| `notes/` | Your notes, one file per chapter | Yes |
| `practice/` | Problems you work, with your steps and results | Yes |
| `formulas/` | Your own formula sheet | Yes |

`catalog.md` is the map of chapters and sections. Open that first when you want a specific part of the book.

## Add the textbook

1. Copy your PDF into `textbook/`.
2. Set the filename in `textbook/README.md` so it is easy to point at later.
3. Leave it there. It is gitignored, so it stays on this computer and can still be read as study context.

## How to study with this folder

- Ask about a section by number, for example “walk me through 4.5 using my notes.”
- Save worked problems in the matching `practice/chXX-*.md` file.
- Put definitions and examples you want to remember in the matching `notes/chXX-*.md` file, in your own words.
- The Fall 2026 syllabus is in [`class/syllabus/syllabus.md`](class/syllabus/syllabus.md). Drop lecture files into `class/`.

Chapters 1–7 are the printed book. Chapters 8–10 are the online chapters in this edition.
