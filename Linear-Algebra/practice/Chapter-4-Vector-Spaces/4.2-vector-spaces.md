# Practice — 4.2 Vector Spaces

Original problems for the skills in section 4.2. Use the PDF for the textbook exercises.

Source PDF: `textbook/Chapter-4-Vector-Spaces/Elementary_Linear_Algebra_-_4.2_Ebooks.pdf`

A set V with addition and scalar multiplication is a vector space when these axioms hold for all vectors **u**, **v**, **w** in V and all scalars c, d:

1. **u** + **v** is in V.
2. **u** + **v** = **v** + **u**.
3. (**u** + **v**) + **w** = **u** + (**v** + **w**).
4. There is a zero vector **0** in V with **u** + **0** = **u**.
5. Each **u** has an additive inverse −**u** in V with **u** + (−**u**) = **0**.
6. c**u** is in V.
7. c(**u** + **v**) = c**u** + c**v**.
8. (c + d)**u** = c**u** + d**u**.
9. c(d**u**) = (cd)**u**.
10. 1**u** = **u**.

---

### Section 4.2 Problem 1

ℝ² has the usual addition, but scalar multiplication is defined by

c(x₁, x₂) = (cx₁, 0).

Which axiom fails? Give a specific counterexample.

---

### Section 4.2 Problem 2

Let V = {(x, y) ∈ ℝ² : x > 0 and y > 0} with the usual addition and scalar multiplication of ℝ². Is V a vector space? Name one axiom that fails and show it.

---

### Section 4.2 Problem 3

On ℝ², define

(x₁, x₂) ⊕ (y₁, y₂) = (x₁ + y₁ + 1, x₂ + y₂ + 1)

and let scalar multiplication be the usual one, c(x₁, x₂) = (cx₁, cx₂).

1. Find a vector **z** such that **u** ⊕ **z** = **u** for every **u**.
2. Show that the scalar 0 times a vector is not equal to that **z**.

---

### Section 4.2 Problem 4

The set of polynomials of degree exactly 2, with the usual addition and scalar multiplication, is not a vector space. Give two different reasons.

---

### Section 4.2 Problem 5

Each of these is a vector space with the usual operations. Name the zero vector, and name the additive inverse of a general element.

1. M₂ₓ₂, the 2 × 2 matrices.
2. C[0, 1], the continuous functions on [0, 1].
3. P₃, the polynomials of degree at most 3.

---

### Section 4.2 Problem 6

Prove that a vector space has only one zero vector. Suppose **0** and **0**′ both act as additive identities, and show they are equal.

---

## Answers

### Section 4.2 Problem 1

Axiom 10 fails: 1(0, 1) = (0, 0) ≠ (0, 1).

### Section 4.2 Problem 2

Not a vector space. The zero vector (0, 0) is not in V, so axiom 4 fails. Scalar closure also fails: −1 · (1, 1) = (−1, −1) is not in V.

### Section 4.2 Problem 3

**z** = (−1, −1). Then 0(x₁, x₂) = (0, 0) ≠ (−1, −1).

### Section 4.2 Problem 4

The zero polynomial does not have degree 2, so it is not in the set. The set is also not closed under addition: x² + (−x² + x) = x, which has degree 1.

### Section 4.2 Problem 5

The zero element of M₂ₓ₂ is the 2 × 2 zero matrix, and the inverse of A is −A. The zero element of C[0, 1] is the function that is 0 at every point of [0, 1], and the inverse of f is −f. The zero element of P₃ is the zero polynomial, and the inverse of p is −p.

### Section 4.2 Problem 6

**0** = **0** + **0**′ = **0**′, because **0**′ is an identity and **0** is an identity.
