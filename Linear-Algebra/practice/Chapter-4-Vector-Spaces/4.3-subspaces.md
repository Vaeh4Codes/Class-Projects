# Practice — 4.3 Subspaces of Vector Spaces

Original problems for the skills in section 4.3. Use the PDF for the textbook exercises.

Source PDF: `textbook/Chapter-4-Vector-Spaces/Elementary_Linear_Algebra_-_4.3_Ebooks.pdf`

A nonempty subset W of a vector space V is a subspace when it is closed under addition and under scalar multiplication. Equivalently, **0** is in W, and c**u** + **v** is in W whenever **u**, **v** are in W and c is a scalar.

---

### Section 4.3 Problem 1

Let W = {(x, y, z) ∈ ℝ³ : x + y + z = 0}. Use the subspace test to decide whether W is a subspace of ℝ³.

---

### Section 4.3 Problem 2

Let W = {(x, y) ∈ ℝ² : x + y = 1}. Show that W is not a subspace of ℝ².

---

### Section 4.3 Problem 3

Let W = {(x, y, z) ∈ ℝ³ : x = 2y and z = 0}. Is W a subspace of ℝ³? If it is, give a specific nonzero vector in W.

---

### Section 4.3 Problem 4

Let W = {(x, y) ∈ ℝ² : xy = 0}. Show that W contains the zero vector and is closed under scalar multiplication, but is still not a subspace.

---

### Section 4.3 Problem 5

Let W = {A ∈ M₂ₓ₂ : det(A) = 0}. Show that W is not a subspace of M₂ₓ₂.

---

### Section 4.3 Problem 6

Let W = {p ∈ P₃ : p(0) = 0}, where P₃ is the set of polynomials of degree at most 3.

1. Show that W is a subspace of P₃.
2. Give one polynomial in P₃ that is not in W.

---

### Section 4.3 Problem 7

Prove: if W₁ and W₂ are subspaces of a vector space V, then W₁ ∩ W₂ is a subspace of V.

---

## Answers

### Section 4.3 Problem 1

Yes. (0, 0, 0) satisfies the equation. If two triples each sum to 0, so does their sum and so does any scalar multiple.

### Section 4.3 Problem 2

(0, 0) is not in W, since 0 + 0 ≠ 1. Also, (1, 0) and (0, 1) are in W, but their sum (1, 1) is not.

### Section 4.3 Problem 3

Yes. It contains (0, 0, 0), and if x = 2y and z = 0, the same relations hold for sums and scalar multiples. One nonzero vector is (2, 1, 0).

### Section 4.3 Problem 4

(0, 0) is in W. If xy = 0, then (cx)y = c(xy) = 0. But (1, 0) and (0, 1) are in W, and their sum (1, 1) has product 1 ≠ 0.

### Section 4.3 Problem 5

Take

```
        ⎡ 1  0 ⎤              ⎡ 0  0 ⎤
A   =   ⎣ 0  0 ⎦      B   =   ⎣ 0  1 ⎦
```

Both have determinant 0, but A + B = I has determinant 1.

### Section 4.3 Problem 6

The zero polynomial satisfies p(0) = 0. If p(0) = q(0) = 0, then (cp + q)(0) = cp(0) + q(0) = 0. The constant polynomial 1 is in P₃ and not in W.

### Section 4.3 Problem 7

**0** is in both subspaces, so it is in the intersection. If **u** and **v** are in both, then c**u** + **v** is in both, so it is in the intersection.
