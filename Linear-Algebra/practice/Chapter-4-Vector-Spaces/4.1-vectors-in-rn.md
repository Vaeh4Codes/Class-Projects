### Section 4.1 Problem 1

Let **u** = (2, −1, 4) and **v** = (0, 3, −2) in ℝ³. Compute **u** + **v**, 3**u**, and 2**u** − **v**.

---

### Section 4.1 Problem 2

Solve for **x** in ℝ⁴:

**x** + (1, −2, 0, 5) = (4, 1, −3, 5).

---

### Section 4.1 Problem 3

Write (5, 1) as a linear combination of (1, 0) and (1, 1). Find the scalars.

---

### Section 4.1 Problem 4

Find a and b such that

a(1, 2, −1) + b(2, −1, 1) = (0, 5, −3).

---

### Section 4.1 Problem 5

Decide whether each statement is true or false. Give a one-line reason.

1. (3, 0, 1) and (3, 0) are the same vector.
2. The zero vector of ℝ⁴ is (0, 0, 0).
3. For all vectors **u**, **v** in ℝⁿ and every scalar c, c(**u** + **v**) = c**u** + c**v**.
4. If 2**u** = 2**v** in ℝⁿ, then **u** = **v**.

---

### Section 4.1 Problem 6

Let **u** = (1, 2) in ℝ².

1. Compute −**u** and −2**u**.
2. Describe, in words, where −2**u** sits relative to **u**.

---

## Answers

### Section 4.1 Problem 1

**u** + **v** = (2, 2, 2), 3**u** = (6, −3, 12), and 2**u** − **v** = (4, −5, 10).

### Section 4.1 Problem 2

**x** = (3, 3, −3, 0).

### Section 4.1 Problem 3

4(1, 0) + 1(1, 1) = (5, 1).

### Section 4.1 Problem 4

a = 2 and b = −1.

### Section 4.1 Problem 5

1. False: (3, 0, 1) ∈ ℝ³ and (3, 0) ∈ ℝ².
2. False: the zero vector of ℝ⁴ is (0, 0, 0, 0).
3. True: c(**u** + **v**) = c**u** + c**v**.
4. True: multiply both sides of 2**u** = 2**v** by ½.

### Section 4.1 Problem 6

−**u** = (−1, −2) and −2**u** = (−2, −4). The vector −2**u** is on the same line as **u**, points the opposite way, and is twice as long.
