# Practice — 4.4 Spanning Sets and Linear Independence

Original problems for the skills in section 4.4. Use the PDF for the textbook exercises.

Source PDF: `textbook/Chapter-4-Vector-Spaces/Elementary_Linear_Algebra_-_4.4_Ebooks.pdf`

A vector **b** is in span{**v**₁, …, **v**ₖ} when

**b** = c₁**v**₁ + ⋯ + cₖ**v**ₖ

for some scalars. The set is linearly dependent when some nontrivial choice of scalars gives **0**. It is linearly independent when the only such choice is all scalars equal to 0.

---

### Section 4.4 Problem 1

Do (1, 2) and (2, 4) span ℝ²? Are they linearly independent?

---

### Section 4.4 Problem 2

Does S = {(1, 0, 0), (0, 1, 0), (1, 1, 0)} span ℝ³? Is S linearly independent?

---

### Section 4.4 Problem 3

Determine whether (1, 2, 3), (2, 1, 0), and (1, −4, −9) are linearly independent in ℝ³. If they are dependent, give a nontrivial dependence relation.

---

### Section 4.4 Problem 4

Find scalars, not all zero, such that

c₁(1, 1) + c₂(2, 3) + c₃(3, 4) = (0, 0).

---

### Section 4.4 Problem 5

Explain why each set is linearly dependent, without row reducing a large matrix.

1. Any set that contains the zero vector.
2. Any set of 4 vectors in ℝ³.
3. {(1, −2), (3, 0), (−1, 4), (2, 2)} in ℝ².

---

### Section 4.4 Problem 6

Let S = {1, x, x²} inside P₂, the polynomials of degree at most 2.

1. Does S span P₂?
2. Is S linearly independent?

---

### Section 4.4 Problem 7

For which real numbers h is

Sₕ = {(1, 0, 1), (0, 1, 1), (1, 1, h)}

linearly independent? For those same values, does Sₕ span ℝ³?

---

## Answers

### Section 4.4 Problem 1

They do not span ℝ². Since (2, 4) = 2(1, 2), the span is the line through (1, 2). They are dependent:

2(1, 2) + (−1)(2, 4) = (0, 0).

### Section 4.4 Problem 2

The span is the plane z = 0, so S does not span ℝ³. It is dependent:

(1, 1, 0) = (1, 0, 0) + (0, 1, 0).

### Section 4.4 Problem 3

Dependent. One relation is

3(1, 2, 3) − 2(2, 1, 0) + (1, −4, −9) = (0, 0, 0).

### Section 4.4 Problem 4

One solution is c₁ = −1, c₂ = −1, c₃ = 1. Any nonzero multiple of that triple also works.

### Section 4.4 Problem 5

A set containing **0** is dependent because 1 · **0** = **0** is a nontrivial relation. Four vectors in ℝ³ are dependent because a homogeneous system with more unknowns than equations has a free variable. The set in ℝ² is dependent for the same reason: more than 2 vectors in ℝ² are dependent.

### Section 4.4 Problem 6

Yes and yes. Every polynomial a + bx + cx² is that combination of S, and a + bx + cx² = 0 forces a = b = c = 0.

### Section 4.4 Problem 7

Independent exactly when h ≠ 2. For those h, three independent vectors in ℝ³ form a basis, so they span ℝ³. When h = 2,

(1, 1, 2) = (1, 0, 1) + (0, 1, 1).
